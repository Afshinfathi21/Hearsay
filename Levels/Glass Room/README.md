# The Glass Room

Level-specific content for the pantomime and observation-glass level.

## Planned folders

- `Scenes/`: Godot scenes for the performer room, observation room, and complete level.
- `Scripts/`: Level-specific orchestration and gameplay scripts.
- `UI/`: Performer and observer interfaces.
- `Data/`: Secret prompts, categories, difficulty settings, and round configuration resources.
- `Tests/`: Tests for level rules and round flow.

No gameplay implementation is included yet. This branch currently contains project structure only.
