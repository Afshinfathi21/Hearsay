# The Glass Room Assets

Assets used exclusively by The Glass Room level.

## Planned folders

- `models/`: Room geometry, glass partition, furniture, and props.
- `materials/`: Level-specific materials.
- `textures/`: Level-specific textures.
- `audio/`: Environmental audio and level sound effects.
- `animations/`: Level-specific animation assets.

Shared character models and reusable gesture resources should remain in their existing shared locations unless a later design decision requires otherwise.
