# Shared Gesture System

Planned reusable full-body gesture system for Hearsay characters.

This system is intended to support reusable body poses and gestures, including arm positions, hand poses, finger configurations, head direction, and combined gestures.

## Planned folders

- `Controllers/`: Runtime controllers for body parts and gesture composition.
- `Data/`: Reusable gesture definitions and pose resources.
- `Tests/`: Tests for gesture data and controller behavior.

The gesture system is not implemented yet. Keep it independent from individual levels so other levels can reuse it.
